# 🎮 GamerZone

Aplicación web desarrollada en React para la gestión y visualización de productos de una tienda gamer.

## 🚀 Tecnologías
- React
- JavaScript
- CSS
- React Router

## 📦 Funcionalidades
- Visualización de productos
- Navegación entre páginas
- Carrito de compras (Cart)
- Componentes reutilizables

## 📁 Estructura
- `/src/components`
- `/src/pages`
- `/src/context`

## ▶️ Cómo correr el proyecto
```bash
npm install
npm start
